# Cirra v0.4.4 - Everyday polish and reliability

Clearer library controls, safer imports and launches, and a more usable manual reader.

- Library search has its own row and a clear action. Controls wrap, collection overflow stays reachable, and filters no longer squeeze collection tabs.
- Help is available from the title bar, F1, and command search, with first steps and controls for desktop and Horizon.
- Multi-root scans run under one cancellable operation and retain useful counts and warnings even when nothing matches.
- Repeated clicks cannot start the same game twice during preparation. Imports cannot overlap, and success notifications count only committed games.
- Late metadata and artwork responses respect the original game and selection.
- Horizon analog navigation resists diagonal/dead-zone jitter and waits for neutral controls when returning from a game.
- Manuals support controller page turns and B to close, bounded PDF rendering/cache memory, current-spread retry, and Home/End navigation.
- Shutdown saves active tracked time before the final library flush and releases background resources.
- Shared input hints and keyboard focus styling improve forms throughout the app.

The installer and portable package are attached with SHA-256 checksums. Existing installations using the GitHub feed can update in-app. The broader visual and hardware validation roadmap remains in progress.
