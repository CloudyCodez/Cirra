# Cirra v0.4.3

This update fixes a Steam discovery blind spot reported by testers after the scanner overhaul.

## What changed

- Detects Steam's actual Windows install location through Valve's registry records.
- Finds libraries when Steam is installed on another drive or inside a custom nested folder.
- Imports new titles from their authoritative Steam manifests, including Castlevania: Belmont's Curse (`4231820`).
- Keeps App ID based identities and duplicate prevention intact across rescans.
- Continues scanning other Steam libraries when one location is locked or temporarily unavailable.

## Verification

- 179 core tests passed.
- 110 desktop app tests passed.
- Installer and portable packages are built from the same `v0.4.3` source revision.

Existing Cirra installations can install this release through the in-app updater. The installer and portable tester package are also attached below.
