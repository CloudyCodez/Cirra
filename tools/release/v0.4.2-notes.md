# Cirra 0.4.2

This update makes Cirra's library scanner considerably more dependable, especially for newer games whose executables use internal names or launcher-specific wrappers.

## Highlights

- Steam, Epic, and Xbox installs are now discovered from their launcher manifests before Cirra falls back to a broad folder scan.
- Steam games retain their App ID and launch through Steam directly instead of relying on a guessed executable.
- Epic and Xbox manifest launch targets are recognized, including Xbox `MicrosoftGame.Config` packages.
- Storefront and install-root identities now survive preview, import, restart, and future rescans.
- Overlapping scan roots and manifest/folder results merge when they represent the same installation.
- Duplicate cleanup can recognize the same provider identity across changed paths while keeping unrelated same-title games separate.
- Directly scanning an individual game folder now preserves the folder's product identity.

## Testing

The Release build completes with zero warnings and zero errors. All 288 automated tests pass: 110 application tests and 178 Core/Data tests.
