# Cirra Closed Beta Testing Guide

Thank you for taking the time. We are looking for honest friction, not a perfect score.

## First Session

- Confirm Cirra opens directly and returns normally after restarting.
- Add one game or folder you are comfortable using for testing.
- Scan the same folder a second time. Existing games should be identified instead of offered as new imports. If you move or copy one scanned file, Cirra should leave it unchecked and explain the possible match.
- Run the launcher-library scan if you use Steam, Epic, or Xbox. Check that games with unusual executable names are still found and that a manifest result does not appear again as a separate folder-scan result.
- Select a game, open its details, and return to the Library without losing your selection.
- Enter and exit Horizon. Check that loading feels smooth and the selected game remains stable while the dashboard rotates content.

## Feature Checks

- Try a library filter, search, favorite, and a metadata refresh. Note any confusing label, delay, or visual overlap.
- Manually edit a title or summary, save it, then refresh metadata. Your edited field should remain protected while other missing details can still improve.
- If you use a controller, test D-pad and left stick navigation, A/B actions, shoulder-page changes, disconnect/reconnect, and whether focus stays clear. Mention the controller model and whether a mapper such as Steam Input was active.
- If you emulate, launch one game through its mapped emulator/core. Include platform, emulator/core, and any error text when it fails.
- Try guide discovery for one game. If Cirra finds a document, attach it and open it. Test page navigation and facing pages. Do not upload or share restricted PDFs.
- Switch themes, then revisit Library and Horizon. Report unreadable text, noisy motion, missing art, or controls that move unexpectedly.
