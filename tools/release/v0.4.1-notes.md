# Cirra 0.4.1

This is Cirra's largest foundation update yet: a faster, more dependable library engine underneath the visual identity that makes Cirra and Horizon their own thing.

## Highlights

- Rebuilt library scanning with stronger identity matching, artifact reconciliation, and duplicate prevention.
- Expanded metadata workflows with protected user edits, better source handling, and clearer repair tools.
- More reliable launching and emulation setup, including improved platform and RetroArch handling.
- A broader Horizon dashboard pass with controller navigation, case and grid presentation, smoother movement, and launch polish.
- Manuals and guide discovery, preservation, and Cirra's book-style reading experience.
- Refined themes, motion effects, glass surfaces, splash transitions, and day-to-day interaction polish across Cirra.
- Access keys are gone. Cirra now opens directly for every tester.

## Updates

Cirra now uses a repository-owned update feed and verifies every installer against its SHA-256 checksum and exact byte count. Interrupted or failed installs pause automatic retry for that version, preventing update loops while keeping a clear manual retry available. Successfully installed packages are cleaned up automatically.

## Downloads

- `Cirra-Setup-v0.4.1.exe` is the recommended Windows installer and supports future in-app updates.
- `Cirra-v0.4.1-closed-beta-win-x64.zip` is the portable tester package.

Windows may display an unknown publisher warning because this beta is not yet code-signed. Verify downloads with the included `.sha256` files.
