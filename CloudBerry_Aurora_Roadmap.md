# CloudBerry: Aurora Release

**Tagline:** The public-ready build where CloudBerry stops feeling like a powerful private app and starts feeling like a polished game-library home.

> **Status (audited 2026-09-03):** This is the historical Aurora delivery record. Implemented work and remaining work have been reconciled against the repository; active forward planning now lives in `CloudBerry_AuroraV2.md`. Aurora is substantially implemented, but is **not release-verified** until its visual, emulation, installer, and real-world launch gates are completed.

## Audit Snapshot

- **Implemented in source:** Phase 1, Phase 2, Section 7, the provider controls and offline messaging in Section 8, detected emulator mapping, and the embedded RetroArch launch path.
- **Implemented but not yet proven in a real release flow:** automated test/build confirmation, minimum-size layout review, embedded RetroArch play-testing, controller/focus navigation, fresh-install and upgrade testing, and installer/update-feed verification.
- **Current test signal:** `dotnet test CloudBerry.slnx` exited with code `1` during this audit, but the current shell emitted no diagnostic output or diagnostic log. Treat the test gate as failing and diagnose it before release work is considered verified.
- **Still open:** the unchecked items below, except for the detected-emulator action corrected in Section 9. The active prioritization, including new V2 feature work, is maintained in `CloudBerry_AuroraV2.md`.

This roadmap is big on purpose, but it's organized so we can ship soon instead of drowning in ambition. The idea is: stabilize first, make every existing system clean and trustworthy, then add a few "oh wow" features that make CloudBerry feel different from Playnite, LaunchBox, and GOG Galaxy.

## Release Goal

CloudBerry Aurora should be ready for a public release candidate when:
- A fresh user can install it, scan/import games, understand the UI, and recover from mistakes.
- Achievements sync, track, unlock, and toast reliably.
- Metadata/artwork flows feel simple for normal users but still powerful for advanced users.
- Emulation setup feels like a first-class feature, not a settings maze.
- Cloudscape/Big Picture feels polished enough to show in screenshots.
- Offline/network failures degrade cleanly.
- Build, tests, installer, update feed, and versioning are all release-grade.

### 3. Achievement System: Make It Bulletproof

Updated `RetroAchievementsProviderTests.cs` to lock in the corrected behavior and added a case proving `TrueRatio` is ignored even when present.
